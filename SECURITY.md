# Política de seguridad

Si encuentras una vulnerabilidad, **no abras un issue público**. Usa "Report a vulnerability" en la pestaña Security del repositorio de GitHub y describe el problema, cómo reproducirlo y su impacto.

Respondemos lo antes posible. Mientras el proyecto esté en desarrollo no hay versiones en producción con soporte.

Controles automáticos: CodeQL, revisión de dependencias, auditoría de paquetes, búsqueda de secretos y escaneo de imágenes (ver `docs/06-ci-cd.md`).
